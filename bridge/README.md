# bridge/ — ערוץ תקשורת Claude ↔ Codex

תיקייה משותפת שגם Claude (כאן) וגם Codex (אצלך) ניגשים אליה. בלי קופי־פייסט.

- `inbox/`  — משימות ל-Codex (ספֵקים ש-Claude כותב). Codex קורא מכאן.
- `outbox/` — דוחות מ-Codex בחזרה. Claude קורא מכאן ומאמת.
- `STATUS.md` — פנקס מצב לכל משימה.
- `PROTOCOL.md` — החוזה: סטטוסים ופורמט דיווח.

הכללים הקבועים ל-Codex נמצאים ב-`AGENTS.md` בשורש (Codex קורא אותו אוטומטית).
