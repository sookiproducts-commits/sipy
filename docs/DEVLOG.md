# Sippy — DEVLOG (יומן המסע)

חומר גלם ל-build-in-public. נכתב בזמן אמת, כולל כישלונות ודחיות. **אל תלטש בדיעבד** — הגולמיות היא הערך.

## המניפסט (הבסיס לביו/פוסט הראשון)
מעצבת UX שמתמחה במערכות מורכבות (חוקים עסקיים, תפקידים, הרשאות, מקרי קצה). בשנה האחרונה AI הפך לחלק מרכזי מאופן העבודה. הניסוי: לקחת רעיון קטן מהראש למוצר אמיתי בעזרת סוכני AI — כשאני אחראית על החשיבה, הטעם, הביקורת וההחלטות, וה-AI מבצע כמה שיותר מההפקה. שאלה: **מה מעצב.ת מוצר עדיין צריך.ה לעשות בעצמו.ה ב-2026, מה כבר אפשר להעביר לסוכנים, וכמה זמן/כסף באמת נדרש כדי להרים מוצר קטן לבד — והאם הוא יכניס שקל.** התיעוד = הפצה אורגנית + ניסוי מקצועי. לא סיפור הצלחה מלוטש; ההתלבטויות והכישלונות בזמן אמת הם העיקר.

## המוצר
Sippy — מעקב מים "אנטי־אפליקציה": בלי חשבון, בלי היסטוריה, בלי התראות, כמעט בלי טקסט. פתיחה → הקשה → סגירה.

## ציר החלטות (בזמן אמת)
- **הרעיון:** רציתי tracker למים שלא יבקש חשבון, לא ישלח notification, ולא יהפוך כוס מים לפרויקט ניהול ביצועים.
- **מוצר:** PWA, מקומי (localStorage), איפוס בחצות, 9 שפות + RTL, יחידות לפי אזור, חינם עכשיו → אולי 5$ בהמשך (מותנה בוולידציה).
- **מותג — סדרת הדחיות (הזהב לסיפור):**
  - v1 "חמוד" → נפסל: ילדותי מדי (פרצופים, קונפטי).
  - v1b מינימלי־שקט עם Frank Ruhl Libre → נפסל: FRL סריף מסורתי/עיתונאי, לא עכשווי.
  - v2 "bold flat" כחול+קוראל, פונט גיאומטרי → נפסל: "נראה גרוע", קר וקורפורטיבי, פספס את החום.
  - **תובנה:** אחרי שראיתי את הרפרנס Maed הבנתי את הטעם האמיתי — bold flat, אבל **חם ואדמתי**: שחור גרפי שטוח, פלטה של זית/חרדל/קרם/ורוד־עמום, טיפוגרפיה אדיטוריאלית (סריף), תחושה טקטילית/רטרו (sticky notes, סקיצות). v3 יילך לשם.
- **תשתית AI:** מערכת סוכנים (מנהל מוצר, art director, UX, build, QA, מוניטיזציה, SEO/GEO, הפצה, content), גשר Claude↔Codex, GitHub + CI, בדיקות מתוזמנות, תקצוב מכסה (Claude+Codex Pro).
