# Sippy — מערכת הסוכנים (קבצי הגדרה)

כל קובץ md כאן הוא **הגדרת סוכן**: frontmatter (שם, תיאור, מודל, כלים, רמת אוטונומיה) + גוף (מטרה, יעדים, וורקפלואו, תוצרים, DoD, שער אנושי, תיעוד, מדיניות כשל).

## מבנה
- `_TEMPLATE.md` — תבנית לסוכן חדש
- `GOALS.md` — יעדי הפרויקט (G1–G5)
- `ORCHESTRATION.md` — וורקפלואו משולב (מקביל/שרשרת)
- `OPERATIONS.md` — דוחות, אישורים, תיבת המשימות שלך
- `<agent>.md` × 14 — הגדרת כל סוכן

## איך מפעילים (Claude Code)
מעתיקים את קובצי הסוכן ל-`.claude/agents/` בפרויקט. אז אפשר להפעיל סוכן לפי שמו. מפעילים בהדרגה לפי מפת ההפעלה (טרום־השקה → השקה → כשמצדיק).

## מודלים
- **opus** — שיפוט/אסטרטגיה/כתיבה (Art Director, UX, Content, Ads, Product, Monetization)
- **sonnet** — בנייה/בדיקות/תפעול (Build, QA, Release, Analytics, SEO/GEO, Scout, Experiment)
- **haiku** — שמור למשימות מכניות זולות במיוחד (לפי צורך)

מקור אמת מלא: `sippy-agent-system.html`.
