# Sippy — תפעול: דוחות, אישורים, ותיבת המשימות שלך

## תיקיות
```
sipy/
├─ reports/         # דוחות יומיים/שבועיים אלייך
├─ queues/          # ממתין לאישורך (עם מזהה לכל פריט)
├─ tasks-for-you/   # משימות שהן באחריותך
├─ decisions/       # מה אישרת/דחית + נימוק
└─ logs/            # יומן פעולות של כל סוכן
```

## הדוח היומי — איך מגיע ומה מכיל
**איך:** משימה מתוזמנת (סשן בוקר) כותבת `reports/daily-YYYY-MM-DD.md`, שולחת אותו אלייך כאן בצ'אט (כרטיס קובץ), ואם תרצי — התראה לטלפון.
**מכיל (בסדר קבוע):**
1. **מה נעשה** — שורה לכל סוכן פעיל (פעולה + קישור ללוג).
2. **מדדים** — תמונת שימוש (כשיש אנליטיקס).
3. **מחכה לאישורך** — פריטים מ-`queues/` עם מזהה + המלצה.
4. **המשימות שלך** — מ-`tasks-for-you/` עם דדליין וזמן משוער.
5. **חסמים** — מה תקוע ולמה.
6. **24 השעות הבאות** — מה מתוכנן.

## איך את מאשרת
כל פריט אישור מקבל **מזהה** (למשל `APR-2026-08-17-01`). את מאשרת באחת משתיים:
- לענות כאן בצ'אט: "מאשרת APR-…-01" / "דוחה APR-…-02 כי…".
- או לסמן בקובץ `queues/…`.
הריצה הבאה קוראת את `decisions/` ופועלת רק על מה שאושר. **בלי אישור — שום דבר בלתי־הפיך/כספי/פומבי לא קורה.**

## איך מגיעות משימות שהן באחריותך
כל פריט ב-`tasks-for-you/` כולל: **מה · למה · זמן משוער · דדליין · איך לבצע · עדיפות.**
הן מרוכזות בסעיף 4 של הדוח היומי, וגם נשלחות כפריטים בודדים כשהן דחופות (למשל KYC לספק תשלום, חיבור דומיין).

## מתג עצירה
כל המשימות המתוזמנות ניתנות להשבתה מיידית. את שולטת בקצב.
